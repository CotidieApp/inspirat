# Identidad de inspíraT

El logotipo escrito es **inspíraT**: minúscula inicial, tilde en `í` y `T`
final mayúscula. La `T` funciona como cursor/pluma y nunca se elimina del nombre
visible.

- Tinta profunda: `#172A2D`
- Verde petróleo: `#1E5B57`
- Champaña: `#C8A96B`
- Terracota de alerta: `#B75D4A`
- Papel: `#F8F5EE`
- Sepia: `#F3E7D0`
- Éxito/sincronizado: `#2C6E61`

La interfaz usa superficies cálidas, esquinas moderadas y suficiente aire. El
icono oficial es la `T` blanca integrada con una pluma estilográfica sobre un
degradado verde petróleo oscuro, recuperado del respaldo original. No debe
reemplazarse por iniciales tipográficas improvisadas. Fuentes: una sans del
sistema para controles y una serif configurable para el texto del escritor.
